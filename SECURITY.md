# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of **NodeBrief** seriously. If you discover a security vulnerability, please do not open a public GitHub issue.

Instead, please email the maintainer directly at **security@nodebrief.dev** or report via private security disclosures on GitHub.

### What to include in your report:
- Type of vulnerability (e.g., XSS, prototype pollution, secret exposure)
- Step-by-step instructions or proof-of-concept script to reproduce the issue
- Affected components or file paths
- Any proposed remediation or patch

We will acknowledge receipt of your report within 48 hours and provide regular updates on remediation progress.
